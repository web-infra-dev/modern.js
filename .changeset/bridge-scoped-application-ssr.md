Support server rendering and hydration of Modern Module Federation application exports using their existing route scopes. Restore loader and deferred data per instance, reuse server DOM, and retain the root, router and page state during prop updates. Preserve consumer basenames and the existing Browser, Hash and explicit memory navigation modes.

复用已有路由选区，为 Modern Module Federation 应用导出接入服务端渲染与水合。按实例恢复 loader 和 deferred 数据，复用服务端 DOM，并在 props 更新时保留 Root、Router 和页面状态。保留消费者 basename，以及现有 Browser、Hash 和显式 memory 导航模式。
