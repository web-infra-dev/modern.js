Add MCP Apps with a versioned UI manifest separating React and Module Federation card builds from official MCP SDK servers. Load UI manifests internally when registering resources. Provide explicit BFF and Fetch adapters, a development Inspector, and MCP project templates.

新增 MCP Apps 支持，通过版本化 UI 清单分离 React、Module Federation 卡片构建与官方 MCP SDK 服务端，注册资源时自动加载 UI 清单，提供显式 BFF、Fetch 适配、开发调试器和 MCP 项目模板。
