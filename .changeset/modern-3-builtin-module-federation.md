Integrate Module Federation as a built-in Modern.js capability. Automatically detect module-federation.config.ts, expose moduleFederation adapter options, preserve the existing CSR/SSR and data-fetch behavior, and reject simultaneous legacy-plugin registration. Set moduleFederation to false to retain the legacy integration. Runtime APIs and types use the unified enhanced/runtime entry without extra lower-level runtime application dependencies.
