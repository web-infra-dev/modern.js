Add an experimental MCP Apps core with mcp_apps.ts definitions, configuration and handler loaders, result/view binding, and an MF/Vmok browser renderer. Servers and remote UI deploy independently without a custom UI manifest, Modern.js app-tools or DevTools. Includes strict JSON Schema validation and a stateless HTTP handler.

Add self-contained local React views and a reusable Hono adapter; Module Federation is optional.
