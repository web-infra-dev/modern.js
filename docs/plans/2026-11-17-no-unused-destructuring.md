# 注册无用解构检查

## Decision Brief

**Intent**：避免通过给无用解构绑定添加 `_` 前缀来绕过检查。

**Outcome**：无用的 `_matches` 解构绑定会被 lint 拦截，有效的属性剔除、变量读取和完整参数占位通过。

**Scope**：仓库本地 Rslint 插件、规则注册和通过真实 CLI 执行的回归检查。

## 执行计划

这是中等规模的 lint 能力补充。现有规则已经检查普通未使用变量，但推荐配置豁免以 `_` 开头的变量和参数。新增规则只补齐这些被豁免的对象解构绑定，避免重复诊断。

1. 在 `scripts/lint/no-unused-destructuring.mjs` 中实现 AST 和作用域引用检查，通过 `rstack.config.mts` 注册 `modern/no-unused-destructuring`。
2. 在 `tests/lint/` 中加入真实 CLI 回归检查，并通过现有 `test:lint` 命令运行。覆盖局部和参数解构、嵌套、默认值、读写引用、遮蔽变量以及 rest 剔除。
3. 扫描全仓，确认现有合法写法通过，执行验证后提交并更新 PR #9178。

边界：只检查声明中的对象解构。普通未使用绑定继续由原规则负责。只有同层 rest 绑定被读取时，才将其兄弟属性视为有意剔除。完整 `_args` 参数、类型断言和数组占位不在新增规则范围内。规则不自动修复，以保留函数参数数量、默认值和属性读取的行为。

风险：作用域 API 或插件加载行为可能与文档不同，必须通过当前 Rslint 的真实 CLI 验证注册及诊断。无法确认绑定身份时不猜测同名变量。
