# Head

Used to add html elements (such as title, meta, script, etc.) to the `<head>` element, supports SSR.

String and streaming SSR collect head data separately for each render, so concurrent renders do not share state. The framework provides the collection context automatically, without requiring an additional Provider.

Streaming SSR reads head data when the shell is ready, or when all content is ready in modes that wait for the complete render. Tags rendered inside Suspense after the shell has been sent are not added to the head that was already sent.

## Usage

```tsx
import { Helmet } from '@modern-js/runtime/head';

export default () => <Helmet>...</Helmet>;
```

## Example

```tsx
import { Helmet } from '@modern-js/runtime/head';

function IndexPage() {
  return (
    <div>
      <Helmet>
        <title>My page title</title>
        <meta name="viewport" content="initial-scale=1.0, width=device-width" />
      </Helmet>
      <p>Hello Modern.js!</p>
    </div>
  );
}

export default IndexPage;
```

## More

For component props, see [react-helmet-async](https://www.npmjs.com/package/react-helmet-async/v/2.0.5).

The peer dependency range of `react-helmet-async@2.0.5` does not include React 19. React 19 projects may receive peer warnings with default installation settings, and installation may fail when strict peer checks are enabled.

If a project directly declares both `react-helmet-async@2.0.5` and React 19 as dependencies, npm 10 may also fail with `ERESOLVE` under its default installation settings.
