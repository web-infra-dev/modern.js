# Logs Events

Log events are distributed by Modern.js as events of type `log`.

## Built-in Events

Based on server-side runtime logic, Modern.js provides the following log events:

| Stage         | Message                                       | Level |
| ------------- | --------------------------------------------- | ----- |
| RENDER_HTML   | App Render To HTML                            | error |
| RENDER_STREAM | An error occurs during streaming SSR          | error |
| RENDER_SHELL  | An error occurs during streaming render shell | error |

## Request headers in error logs

Modern.js omits `cookie`, `set-cookie`, `authorization`, `proxy-authorization`, `x-api-key`, and `x-proxy-auth` when it logs request headers for SSR or server errors. Other headers, such as `x-request-id`, are available for troubleshooting.

Use `server.logger.redactHeaders` in `modern.config.ts` to add names to the default list. Header names are case-insensitive.

```ts
import { defineConfig } from '@modern-js/app-tools'

export default defineConfig({
  server: {
    logger: { redactHeaders: ['X-Internal-Token'] },
  },
})
```
