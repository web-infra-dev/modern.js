Modern.js 提供了 `@modern-js/create` 工具来创建项目，不需要全局安装，直接使用 `npx` 按需运行即可。

你可以在已有的空目录来创建项目：

```bash
mkdir myapp && cd myapp
npx @modern-js/create@latest
```

也可以直接用新目录创建项目：

```bash
npx @modern-js/create@latest myapp
```

`@modern-js/create` 会直接创建应用，不再提供问答界面：

```bash
🚀 欢迎使用 Modern.js

📦 正在创建项目 "myapp"...

✨ 项目创建成功！🎉

📋 接下来你可以执行以下命令：

📁 进入项目目录：

  cd myapp

🔧 初始化 Git 仓库：

  git init

📥 安装项目依赖：

  pnpm install

⚡ 启动开发服务器：

  pnpm dev
```

现在，项目结构如下：

```
.
├── modern.config.ts
├── package.json
├── README.md
├── rstack.config.mts
├── src
│   ├── modern.runtime.ts
│   └── routes
│       ├── index.css
│       ├── layout.tsx
│       └── page.tsx
└── tsconfig.json
```

新建的独立项目使用 [Rstack CLI](https://rstack.rs/) 进行代码校验和格式化：

```bash
pnpm check
pnpm format
```
