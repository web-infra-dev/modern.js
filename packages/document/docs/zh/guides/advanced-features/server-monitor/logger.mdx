# 日志事件

日志事件是由 Modern.js 分发的，类型为 `log` 的事件。

## 内置事件

基于服务端运行逻辑，Modern.js 在内部提供了以下日志事件：

| 阶段          | 消息                                          | Level |
| ------------- | --------------------------------------------- | ----- |
| RENDER_HTML   | App Render To HTML                            | error |
| RENDER_STREAM | An error occurs during streaming SSR          | error |
| RENDER_SHELL  | An error occurs during streaming render shell | error |

## 错误日志中的请求头

Modern.js 在 SSR 或服务端错误日志中记录请求头时，默认过滤 `cookie`、`set-cookie`、`authorization`、`proxy-authorization`、`x-api-key` 和 `x-proxy-auth`。日志会保留其他请求头，例如用于排查问题的 `x-request-id`。

可以在 `modern.config.ts` 中通过 `server.logger.redactHeaders` 追加要过滤的请求头，名称不区分大小写。

```ts
import { defineConfig } from '@modern-js/app-tools'

export default defineConfig({
  server: {
    logger: { redactHeaders: ['X-Internal-Token'] },
  },
})
```
