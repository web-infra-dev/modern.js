# @modern-js/mcp-apps

MCP tools and interactive React views for Modern.js and independently managed servers.

- Define typed tools and views with `defineMcpServer` and `defineTool`
- Serve MCP requests through Web Request/Response, Hono or Modern.js BFF adapters
- Render local React cards or Module Federation components
- Consume application-built UI resources through a versioned manifest

Use `@modern-js/plugin-mcp-apps` for Modern.js build and development integration.
